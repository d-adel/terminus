# Goal Structuring Notation (GSN) Community Standard v3

**Title:** GSN Community Standard Version 3 (2021)

**URL:** https://gsn-community.github.io/ or SCSC (Safety Critical Systems Club) official repository

**Version/Date:** Version 3.0, 2021 (public release)

**Access:** Public standard (Community Standard); some content freely available, full specification paywalled/archived

**Source(s):** Assurance Case Working Group; Goal Structuring Notation community documentation; secondary references.

## Element Types

- **Goal:** "A claim or objective that must be supported by an argument"
- **Strategy:** "An approach to supporting a goal; describes how lower-level sub-goals or solutions achieve the parent goal"
- **Solution:** "Concrete evidence or artifact that directly supports a goal (leaf node); no further argumentation needed"
- **Context:** "Factual statement providing context for interpreting goals, strategies, or other elements"
- **Assumption:** "A statement assumed to be true for the argument; assumptions that are not verified introduce risk"
- **Justification:** "Explanation of why a particular approach (strategy or relationship) is appropriate"
- **Undeveloped goal / Undeveloped element:** "Element for which detailed argumentation is deferred or not required at current level"
- **Away goal:** "Goal relevant to the argument but explicitly outside the current assurance case scope"

## Related Notations (Brief)

- **OMG SACM (Structured Assurance Case Metamodel):** Formal metamodel for assurance cases; supports GSN and other notation mappings
- **Claims-Arguments-Evidence (CAE):** Informal argumentation structure; GSN and SACM are formal implementations of CAE principles
